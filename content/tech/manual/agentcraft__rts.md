Browser-based RTS-style command center (npx @idosal/agentcraft) by Ido Salomon that shows Claude Code, Codex, OpenCode and Cursor agents as units on a tactical map so you can monitor, summon and command them from one pane. Adds remote approvals via mobile PWA push and Telegram/Discord, Docker/Apple container isolation, and shared multiplayer 'Alliance Hall' rooms.
