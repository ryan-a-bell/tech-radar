MCP server that lets AI assistants like Claude Code query, create, modify, validate, and diagram SysML/UML models in a running Cameo Systems Modeler (CATIA Magic) via a Java plugin exposing ~162 tools. Relevant for bringing agent-driven workflows into MBSE; local-only with no auth, and includes a Groovy macro tool.
