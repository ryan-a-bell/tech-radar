Cloudflare's early-stage, schema-first code generation framework: takes OpenAPI 3.x specs, applies JSONPath overlays, and emits typed SDKs, CLIs, and docs through a plugin architecture. Currently powers Cloudflare's own cf CLI, with TypeScript/Go/Python/Terraform targets planned.
