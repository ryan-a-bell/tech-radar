Automated machine learning: automating the expert-heavy parts of the ML workflow — model selection, hyperparameter optimization (e.g. Bayesian/multi-fidelity HPO), neural architecture search, and pipeline/ensemble construction. Tools like auto-sklearn, SMAC, and AutoGluon implement it.
