An agent/Claude skill that turns natural-language descriptions into editable draw.io (.drawio) XML and exports them to PNG/SVG/PDF/JPG via the native draw.io desktop CLI. Can also reverse-engineer diagrams from existing code repos, infrastructure configs, and databases. Covers C4 (with multi-page drill-down), UML, SysML/MBSE (bdd/ibd/req/par), BPMN, ERD, flowcharts, network topology, and 28 Mermaid diagram types.

Note: it does not support the DoDAF or UAF architecture frameworks, but it does have first-class C4 model support.
