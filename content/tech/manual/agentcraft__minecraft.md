Open-source (MIT) Minecraft Java mod plus a Node 'Foreman' that runs a team of Claude Agent SDK (or Codex) coding agents as an in-game studio: a lead agent splits a goal into a task graph, workers code in isolated git worktrees, and you review diffs and click merge yourself. A novel spatial UI for multi-agent coding with human-gated merges; young, singleplayer-only project.
