Free, Apache-2.0 Java discrete-event simulation environment with a drag-and-drop UI, interactive 3D graphics, and palettes for process flow, resources, and fluid flow; custom object palettes can be written in Java. An open-source GUI counterpart to Arena/AnyLogic (paid Pro edition adds transport and material-flow libraries).
