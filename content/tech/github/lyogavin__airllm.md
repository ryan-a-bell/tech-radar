Python library that runs very large LLMs (70B dense up to 2.8T MoE) on a single small GPU by streaming weights layer-by-layer (and per-expert for MoE) instead of loading the whole model, with no quantization required. Now also supports adapter fine-tuning of huge models under ~6GB VRAM — trading throughput for the ability to run frontier open-weight models on consumer hardware.
