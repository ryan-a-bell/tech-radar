Open-source orchestration platform (Node.js server + React dashboard) that wraps multiple AI coding agents (Claude Code, Codex, Cursor, etc.) into a company-like structure — org chart, roles, budgets, goals, task tracking, and audit logs — so several agents can work toward a shared objective without duplicated effort or runaway API spend.
