Clean-room, pure-Rust reimplementation of Photoshop: layers, masks, adjustment layers, layer styles, type, vectors, and byte-faithful PSD round-tripping on a wgpu GPU compositor, native and in the browser via WASM. Every action is a command in a 500+ entry registry, drivable from the UI, a headless CLI, a JSON control channel, or an MCP server. Early alpha.
