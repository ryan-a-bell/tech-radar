Offline desktop app (Electron + React UI, Python backend) that splits any YouTube song into isolated stems (vocals, drums, bass, guitar, piano) using demucs and Mel-Band Roformer models, with per-stem mute/solo/volume, karaoke/acapella presets, and WAV export. Fun local-ML music toy with GPU acceleration on MPS/CUDA/ROCm.
